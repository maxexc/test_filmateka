# Filmoteka

Filmoteka is a collaborative team project focused on delivering an interactive movie search platform. The app provides a sleek and smooth user experience, incorporating advanced features like pagination, smooth scroll, and a dynamic movie carousel.

## Features

- Movie search by title, genre, and year
- Pagination for search results
- Smooth scroll for enhanced UX
- Swiper.js carousel for upcoming movies
- Multilanguage support (English and Ukrainian)
- Commercial Rest API for real-time movie data

## Technologies Used

- JavaScript (ES6+)
- SCSS
- Swiper.js
- Smooth Scroll
- Axios for API requests
- Handlebars.js for templating
- Firebase (planned, inactive)
- Webpack
- Parcel

## Setup and Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/maxexc/test_filmateka.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Install dependencies:
   ```bash
   npm start
   ```
